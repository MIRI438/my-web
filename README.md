# mir.ai | מירי לודמיר · פיתוח ואוטומציות

אתר סטטי בעמוד אחד (HTML/CSS/JS, בלי build), בעברית ומימין לשמאל.

**כיוון עיצובי:** סצנות מלאות בכחול קובלט ושחור, טיפוגרפיה ענקית (Karantina), גלילה חלקה (Lenis), אנימציות גלילה (GSAP ScrollTrigger) ואובייקט חלקיקים תלת־ממדי (Three.js).

## הרצה
פותחים את `index.html` בדפדפן, או מריצים `npx serve .`

## לוגו
`assets/logo.svg` (לרקע בהיר), `assets/logo-white.svg` (לרקע כהה), `assets/mark.svg` (סמל בלבד / אייקון).
