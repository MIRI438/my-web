# Flowbit — אתר תדמית לעסק פיתוח ואוטומציות

אתר סטטי בעמוד אחד (HTML/CSS/JS, בלי build), בעברית ומימין לשמאל.

**כיוון עיצובי:** רקע בהיר, טיפוגרפיה הנדסית (IBM Plex), צבע מרקר צהוב אחד, ורשימת משימות אינטראקטיבית בראש העמוד.

## הרצה
פותחים את `index.html` בדפדפן, או מריצים `npx serve .`
